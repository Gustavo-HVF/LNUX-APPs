# LNUX-APPs

Apps web do [LNUX](https://github.com/Gustavo-HVF/Termux-Toons): programas de criação que abrem no navegador,
feitos só com HTML, CSS e JavaScript, com uma ponte local para as pastas do aparelho e o ffmpeg.

Em construção: os primeiros apps (Vídeo, Som e Efeitos) chegam no primeiro pull request.
